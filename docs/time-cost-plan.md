## 7. Earned Value за Sprint 1
 
| Метрика | Розрахунок | Значення | Джерело в Jira |
|---------|------------|---------:|----------------|
| PV | Заплановані SP × вартість SP | $1,800.00 | Sprint Report → Committed |
| EV | Завершені SP × вартість SP | $1,800.00 | Sprint Report → Completed |
| AC | sum Time Spent × $15 | $1,800.00 | Time Tracking Report |
| **CV** | EV − AC | $0.00 | |
| **SV** | EV − PV | $0.00 | |
| **CPI** | EV ÷ AC | 1.00 | |
| **SPI** | EV ÷ PV | 1.00 | |
| **EAC** | Total Budget ÷ CPI | $4,116.07 | |

| Індекс | Значення | Стан | Інтерпретація |
|--------|:--------:|:----:|---------------|
| CPI | 1.00 | 🟢 | Проєкт виконується суворо в межах запланованого бюджету |
| SPI | 1.00 | 🟢 | Проєкт іде чітко за графіком без відставань |

## 9. Рефлексія

| Питання | Відповідь команди |
| --- | --- |
| Наскільки оцінка в годинах (Subtasks) збіглася зі Story Points? Який коефіцієнт вийшов? | Оцінка збіглася з похибкою до 10%. Коефіцієнт співвідношення годин до SP становить близько 1.54 годин на 1 SP. |
| Чи змінилось розуміння термінів після розрахунку через Velocity? Встигаєте до кінця семестру? | Так, розрахунок через Velocity підтвердив, що за 2 спринти команда гарантовано встигає до кінця семестру (13.12.2026). |
| Що показав CPI/SPI за Sprint 1 і що команда зробить інакше у Sprint 2? | CPI та SPI дорівнюють 1.0, що означає повне виконання планів без відхилень. У Sprint 2 збережемо поточний темп та детальніше контролюватимемо зв'язки завдань. |
| Яка залежність виявилась найнебезпечнішою для проєкту? | Найнебезпечнішими виявилися міжзадачні блокери умовної послідовності, де затримка базових задач авторизації чи моніторингу загрожує зсувом решти епіків. |
